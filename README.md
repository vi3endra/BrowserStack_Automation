# BrowserStack_Automation

Selenium-RSpec Automation Framework for BrowserStack Testathon

# selenium-rspec

[Rspec](http://rspec.info/) Integration with BrowserStack.

## Setup

- Clone the repo
- Install dependencies `bundle install`
- Update .env file for BROWSERSTACK_USERNAME and BROWSERSTACK_ACCESS_KEY with your [BrowserStack Username and Access Key](https://www.browserstack.com/accounts/settings)

## Run the tests

- To run tests, run `bundle exec rake`

Understand how many parallel sessions you need by using our [Parallel Test Calculator](https://www.browserstack.com/automate/parallel-calculator?ref=github)

## Notes

- You can view your test results on the [BrowserStack Automate dashboard](https://www.browserstack.com/automate)
- To test on a different set of browsers, check out our [platform configurator](https://www.browserstack.com/automate/ruby#setting-os-and-browser)
